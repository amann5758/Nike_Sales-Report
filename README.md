# 👟 Nike Sales Analysis | Power BI Dashboard

📊 **Turning Nike Sales Data into Business Insights!** 🚀

Ever wondered how sales data can reveal business growth opportunities? This project explores Nike sales data using **Microsoft Power BI** to transform raw data into meaningful insights through interactive visualizations and data analysis.

### ✨ Project Highlights
- 📈 **Sales Performance:** Analyze sales trends and revenue performance.
- 👟 **Product Analysis:** Explore product-wise sales and performance.
- 🌎 **Regional Insights:** Understand sales distribution across different markets.
- 💰 **Business Intelligence:** Discover patterns that can support data-driven decisions.
- 📊 **Interactive Dashboard:** Visualize key metrics through an engaging Power BI dashboard.

### 🛠️ Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Business Intelligence
- Data Analysis

### 🎯 Project Objective
The goal of this project is to turn Nike sales data into actionable business insights and demonstrate practical skills in data analytics and dashboard development.

### 💡 What I Learned
- Building interactive dashboards
- Analyzing sales performance
- Presenting data through visual storytelling
- Converting business data into meaningful insights
